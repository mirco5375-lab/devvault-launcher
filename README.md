DevVault Launcher

Launcher zum Herunterladen der offiziellen DevVault-Erweiterung und von Community-Erweiterungen.

Starten
Python installieren (Windows: beim Installieren "Add Python to PATH" anhaken)
Einmalig im Terminal: pip install customtkinter pillow
Doppelklick auf devvault_launcher.pyw (startet ohne Terminal-Fenster)
Funktionen
Offizielle Plugins: DevVault (Chrome-Erweiterung) herunterladen und entpacken
Community: eigene Erweiterungen mit Bild und Beschreibung hochladen, Warnhinweis für nicht offizielle Erweiterungen
Feedback: Titel, Sterne und Beschreibung abgeben, alle Feedbacks ansehen

Alle Daten werden dauerhaft gespeichert (Windows: %APPDATA%\DevVaultLauncher).
